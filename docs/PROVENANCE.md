# Provenance and public scope

RelayOps is a portfolio adaptation of a workplace operations project independently implemented by this repository's author. The public Git history starts with preparation of this edition; it does not reproduce the workplace repository's history or imply that the project originated as an unrelated personal product.

The edition preserves general handover, monitoring, incident-management, and assistant workflows while replacing identifying material:

- Organization branding, personal contact details, directory identifiers, internal hostnames, and project examples are replaced with fictional equivalents.
- Local databases, logs, uploads, archives, personal documents, internal deployment bundles, and assistant session material are excluded.
- Public configuration is rebuilt around local mocks and explicitly provided environment variables.
- Private identity/deployment helpers and the private notification transport are omitted.
- The model-monitoring transport is replaced with a new documented synthetic protocol and regression tests.
- Brand-bearing raster assets are replaced with a new RelayOps vector mark.
- Prebuilt frontend artifacts and original Git metadata are excluded; builds run from source.

Fictional test scenarios preserve the types of edge cases under test. They are not evidence of a particular customer's data, production incident, usage scale, or business outcome.

Sanitization is a content and engineering measure. This repository makes no claim that it independently establishes rights to publish or relicense workplace-derived material. No blanket open-source license is added; dependency notices remain applicable to their respective packages.
