## purpose
Resolved Issues is a searchable, platform-wide listing of issues that have been
resolved or closed, so you can look up how a past issue was handled and reuse
the resolution.

## layout
- Header: a Dashboard back button, the "Resolved Issues" title with a count
  badge ("N resolved").
- A search box (search by id, title, type, project, or assignee).
- A table with columns ID / Issue / Type / Assignee / Status / Resolved /
  Details. The Issue cell also shows the project·product context and a
  truncated resolution note. Clicking a row (or the Details button) opens the
  full issue detail dialog.
- Empty states for "No resolved issues yet" and "No matches".

## flow
1. Open it from the Dashboard "Resolved Issues" card (the back button returns there).
2. Type in the search box to filter by id/title/type/project/assignee.
3. Click a row or its Details button to read the full issue and its resolution.

## buttons
- **Dashboard** — back button that returns to the Dashboard.
- **Details** — opens the full issue detail dialog for that row.
